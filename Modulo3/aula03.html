Categoria de HTML 5

Elementos de bloco

Ocupam toda a largura horizintal disponível, exemplo: <div> <p> <h1> <section> <article>

Elemento de linha

Ocupam apenas o espaço necessário na linha, exemplo: <a> <span> <strong> <em> <img>

Regras importantes

Elementos de linha não devem conter elementos de bloco.

Exemplo incorreto:
Texto
Exemplo correto:
Texto

Categorias de conteúdo:

Metadata Content

São informações de configurações do arquivo HTML

<title>: Informa o título da página

<meta>: Definir códificação

<link>: e o <style> Importar/anexar CSS

<script>: Importar/anexar comandos JavaScript

Flow Content:

Representa a maior parte dos elementos usados no body

<div>: Criar uma divisão genérica, agrupar "pedaços" de código

<p> Criar paragráfo dentro da página

<section>: Agrupa conteúdos que partilham do mesmo assunto/ideia

<article>: Conteúdo independente e completo por sí só (faz sentido sozinho)

<img>: Importar imagem, desenho, foto (não precisa de tag de fechamento)

<form>: Criar formulários, o usuário pode digitar dados e/ou enviar mensagem, fazer login

Sectioning Content

Organizae grandes áreas do documento

<section>: Agrupa conteúdos que partilham do mesmo assunto/ideia

<article>: Conteúdo independente e completo por sí só (faz sentido sozinho)

<aside>: Serve para guardar um conteúdo secundário/lateral (links relacionados, anúncios, biografias e etc..)

<nav>: Agrupar links de navegação

Heading Content

h1,h2,h3,h4,h5 e h6: Adicionar títulos e subtítulos

<hgroup>: Agrupar elementos de titulo, exemplo

Phrasing Content

Elementos que marcam textos ou partes de textos

<span>: Um bloco genérico, não muda nada sozinho,porém pode aplicar CSS ou chamar funções com JavaScript

<a>: Criar um link para direcionar o usuário para outra página, utilizando o atributo href Clique para conhecer

<strong>: Serve para deixar uma parte do texto em negrito

<em>: Serve para deixar uma parte do texto em itálico

<mark>: Serve para adicionar um marcador em uma parte do texto Texto

<img>: Importar imagem, desenho, foto (não precisa de tag de fechamento)

Embadded Content

Utilizado para inserir um conteúdo externo

<img>: Importar imagem, desenho, foto (não precisa de tag de fechamento)

<video>: Adicionar um vídeo (Pode mostrar botões de play e pause)

<canvas>: Criar uma tela em branco que poderá ser usada pelo JavaScript

<svg>: Desenhar gráficos baseados em vetores

<iframe>: Colocar outras páginas inteiras dentro do seu website (muito usado para adicionar mapas e vídeos)

Interactive Content

Permite interação com os usuários

<a>: Criar um link para direcionar o usuário para outra página

<button>: Cria botão. Exemplo:

<imput>: Usuário para receber dados do usuários. Dentre os dados aceitos estão:

type= "text": campo de texto curto; type= "password": oculta os caracteres digitados; type= "email" ou "number": valida dados especificos; type= "checkbox" ou "radio": caixas de marcação e escolha única. ***type é uma tag que não precisa de fechamento

<select>: Criar uma caixa de seleção em formato de linha suspensas(dropdown)

<textarea>: Criar uma caixa com várias linhas, serve para textos longos, comentários, mensagens e biografias
